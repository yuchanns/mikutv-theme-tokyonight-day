# Tokyo Night Day for MikuTV

Crisp porcelain and cobalt daytime palette inspired by Tokyo Night Day for MikuTV.

- **Plugin ID**: `tokyonight-day`
- **Kind**: `theme` (`light` appearance)
- **Version**: `1.0.0`
- **License**: Apache-2.0

## Installation

1. Open **MikuTV** on Apple TV.
2. Go to **设置 → 外观与动态 → 选择主题 → 发现更多主题** (or **设置 → 插件管理 → 发现插件**).
3. Select **Tokyo Night Day** (`yuchanns/mikutv-theme-tokyonight-day`) and install.
